# ⛷️ 极速滑雪 · Low Poly 3D Ski Runner

第一人称、低多边形、色彩明快的 **无尽滑雪** 游戏（参考 Microsoft Edge Surf）。
纯前端实现：Three.js + 原生 JS，无构建、无外部素材、双击即可运行。

## 运行
用 VS Code **Live Server** 打开 `index.html`，或直接双击
（需联网加载 Three.js CDN：`cdnjs.cloudflare.com/ajax/libs/three.js/r128`）。

## 操作
| 按键 | 功能 |
|---|---|
| `←` `→` / `A` `D` | 左右移动（带惯性，限制在雪道内） |
| `空格` | 跳跃（越过雪堆/栅栏） |
| `↓` / `S` | 下蹲 · 小幅减速 |
| `空格 / R` | 开始 / 重开 |
| `P` `M` | 暂停 / 静音 |
| 触摸屏 | 按住屏幕左/右侧移动 |

## 玩法与规则
- **自动加速滑行**，速度随距离提升直到上限；避开障碍、收集道具。
- 障碍：🌲树木、🪨岩石（必须绕行）、⛄雪堆、🚧栅栏（跳跃可越过）。
- 道具：金币🪙加分、⚡加速（短暂提速）、🛡护盾（免疫一次撞击）。
- 生命 3 条；撞击会**红屏**并降速 + 短暂无敌；护盾可抵消撞击。
- 得分 = 滑行距离 ×2 + 金币 50 + 道具加分。历史最高分保存在本地。
- 每排障碍保证至少 2 条空道可通行，难度随距离平滑增长。

## 视觉与实现要点
- 第一人称镜头高度 = 雪面 + 1.55m（+跳跃高度），且雪道**坡度恒定、无高频起伏**，
  从根本上避免相机穿入地面；双板 + 雪靴贴合雪面出现在画面下方。
- 低多边形建模：分层锥形松树（雪冠）、顶点色岩石、雪堆、双横木栅栏、
  旋转金币、⚡闪电加速、透明护盾、天空渐变穹顶、远山剪影与低多边形云。
- 方向光软阴影 + 半球环境光 + ACES 色调映射 + sRGB + 指数雾。
- 性能：全部障碍/道具/装饰使用**对象池**滚动回收；雪粒子、喷雪粒子合并在单一
  `Points` 内；远处物件由雾效剔除视觉细节。
