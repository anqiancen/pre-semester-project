### 这里是游戏地图设计层面第一周的总结文档。

我们决定采用像素风格，类似“星露谷“和“传说之下“的地图设计。于是，我们在网上找到了“星露谷“的地图贴图资源，并把其加入到了我们第一版地图中。

我们的地图逻辑如下：

地图分为三层，分别是背景层、静态物品层（又分为小物品、大物品层）和动态物品层。

在渲染地图的时候：先将背景层渲染上去；然后把上面所有层的物品按照y坐标排序，依次渲染，以正确处理遮挡关系。

同时我们对处理交互和对话进行了初步的设计，现在至少能完成简单的对话和分支内容了。对话放在dialogue.js内。

加入了字体和音乐。

#### 后续开发计划：

1.等待剧情出来之后和地编一起编辑出真正适合的地图和交互资源。可能需要另找贴图，或者自己绘制贴图。

3.学习并使用“存储游戏进度“，例如获得了什么道具，是否是与NPC第一次对话等等。这个内容在现在的Demo中完全没有呈现。
