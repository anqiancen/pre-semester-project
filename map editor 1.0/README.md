# 地图编辑器 1.0

这是《冰原计划》的独立地图制作工具，负责制作地图底图、设置地块阻挡，以及制作和导入静态物体。

## 目录结构

```text
map editor 1.0/
├── map_editor.html          # 地图制作和预览
├── object_editor.html       # 静态物体制作
├── js/
│   └── object-editor.js     # 静态物体编辑器逻辑
└── img/                     # 编辑器使用的图片资源
```

## 启动方式

由于页面需要加载图片资源，建议通过本地 HTTP 服务器运行，不要直接双击 HTML 文件。

在终端执行：

```bash
cd "/Users/cz-seven/Desktop"
python3 -m http.server 4174
```

然后打开：

```text
http://127.0.0.1:4174/map%20editor%201.0/map_editor.html
```

静态物体编辑器地址：

```text
http://127.0.0.1:4174/map%20editor%201.0/object_editor.html
```

服务器根目录也可以改成 `map editor 1.0` 文件夹本身，此时访问地址会变成：

```text
http://127.0.0.1:4174/map_editor.html
```

## 制作地图

1. 在“图块图集”中选择图片文件。
2. 在“选择图块”区域选择地面图块。
3. 在地图画布中点击或拖动绘制。
4. 使用“应用尺寸”调整地图大小。
5. 使用“清空地图”清除当前地图。
6. 点击“打开预览”查看不带编辑网格的地图。

图块选择区会按照图片的原始 16 × 16 图块列数排列。不同图集的图块数量可能不同。

## 设置地块阻挡

默认绘制的地块可以通行。

设置阻挡的方法：

1. 先把图块绘制到地图上。
2. 点击“设置阻挡”。
3. 点击某一个地图格。
4. 该格会显示红色半透明标记和斜线，表示玩家不能通过。

再次点击同一个格子可以取消阻挡。相同图片的地块可以分别设置为可通行或不可通行。

## 制作静态物体

打开 `object_editor.html`，可以制作树、房屋、石头等静态物体。

制作流程：

1. 填写中文名称，用于编辑器列表显示。
2. 填写英文 ID，例如 `stone` 或 `large_tree`，这个 ID 会写入游戏地图代码。
3. 选择图集文件。
4. 在 PNG 图集上点击或拖动，选择物体的源图区域。
5. 点击“选择锚点”，再在物体选区内点击锚点格。
6. 填写遮挡遮罩：`#` 表示阻挡，`.` 表示可以穿过。
7. 点击“更新预览”。
8. 复制生成的 JSON 配置。

遮罩必须与物体尺寸一致。例如一个 2 × 2 物体可以写：

```text
..
##
```

## 把静态物体导入地图

1. 打开 `map_editor.html`。
2. 点击“导入新静态物体”。
3. 粘贴静态物体编辑器生成的 JSON。
4. 点击“导入物体”。
5. 在静态物体列表中选择它，再点击地图放置。

## 生成游戏地图代码

地图完成后：

1. 点击“生成地图代码”。
2. 复制生成的 JavaScript 模块。
3. 粘贴到游戏项目的 `maps/map1.js` 或其他地图文件。
4. 根据游戏需要补充出生点、NPC、传送点、BGM 和其他实体。

编辑器生成的地图主要包含：

- `tiles`
- `tileTypes`
- `objectTypes`
- `objectMap`
- `objectChars`
- `sheets`

## 图片资源同步规则

是的，地图制作完成后，游戏项目需要拥有生成代码引用的同名图片，并且路径要一致。

例如生成代码中包含：

```js
sheets: {
  "spring_outdoorsTileSheet.png": "img/spring_outdoorsTileSheet.png",
  "spring_town.png": "img/spring_town.png",
}
```

那么游戏项目必须存在：

```text
game ver 1.2/img/spring_outdoorsTileSheet.png
game ver 1.2/img/spring_town.png
```

文件名、大小写和相对路径都要一致。最简单的做法是把地图编辑器使用的图片复制到游戏项目的 `img/` 文件夹中。

静态物体不需要把编辑器本身复制进游戏项目。只需要：

1. 把生成的地图代码放入 `maps/`。
2. 把地图代码 `sheets` 中引用的图片复制到游戏的 `img/`。
3. 确保地图启动脚本加载对应地图文件。

## 注意事项

- 编辑器当前不会自动保存地图，刷新页面会丢失当前编辑内容。
- 生成代码后要手动复制到游戏项目。
- 地图编辑器中的图片路径相对于地图页面所在位置解析。
- 图片缺失或文件名不一致时，图集和地图会加载失败。
- 生成地图后建议通过游戏页面实际测试碰撞、物体遮挡和绘制层次。
